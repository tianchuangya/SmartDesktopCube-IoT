## 🪛 接线（就三根杜邦线）

```
        你的 ESP32-S3（多余那块）
        ┌──────────────┐
        │              │
        │  GPIO5 ●─────┼──── 杜邦线 ────→ MOS管 IN1（控制暖白）
        │  GPIO6 ●─────┼──── 杜邦线 ────→ MOS管 IN2（控制冷白）
        │  GND   ●─────┼──── 杜邦线 ────→ MOS管 GND
        │              │
        │  USB ●───────┼──── 充电头或电脑供电
        └──────────────┘

        双路MOS管模块                    LED灯带
        ┌──────────┐                ┌──────────┐
        │ VCC ←──────── 5V电源正极 ──→ 灯带正极  │
        │ GND ←──── 接S3的GND       │          │
        │ IN1 ←──── 接S3的GPIO5     │ 暖白线 ──→ OUT1（螺丝拧）
        │ IN2 ←──── 接S3的GPIO6     │ 冷白线 ──→ OUT2（螺丝拧）
        │ OUT1 ────────→ 暖白灯线   │          │
        │ OUT2 ────────→ 冷白灯线   └──────────┘
        └──────────┘
```

---

## 🔤 记住两句话

> **5号脚暖白，6号脚冷白。**
> **杜邦线插三根，螺丝拧两下，插上 USB 就完事。**

## 📲 烧录程序

在 VS Code 中：
1. 用 PlatformIO 打开 `esp32c3_light_controller` 文件夹
2. USB 连接 ESP32-S3 到电脑
3. 点击底部 `→` 上传按钮
4. 打开串口监视器，看到 `[BLE] 服务已启动` 就是成功了

---

## 🧪 测试

1. 接好线并烧录后，ESP32-S3 灯控器通电
2. 你的主项目 ESP32-S3 也会自动搜索 `SmartCube-Light` 并连接
3. 进入 settingsScreen，拖动亮度/色温滑块，灯带跟着变化
