# Smart Desktop Cube IoT — 变更日志 2026-06-19

## 一、变更概述

本次改动围绕一条主线：**PM2.5 AI 预测模型集成** — 将朋友训练好的 LightGBM 模型转换并部署到 ESP32-S3，利用现有传感器（AHT20温湿度 + ENS160 CO2/TVOC）实时预测 PM2.5 浓度，无需额外硬件。

核心挑战：
- LightGBM 模型文件为文本格式（2.8MB / 1000棵树），无法直接在 ESP32 上加载
- ESP32 无 Python 运行时、无 LightGBM 动态库支持
- 需要将模型"编译"成纯 C 数据结构，并实现高性能树遍历推理

解决方案：编写 Python 脚本提取 LightGBM 模型的全部决策树结构，生成为 C 常量数组（存入 ESP32 Flash），再在设备端实现 0-dependency 的树遍历推理引擎。

## 四、技术细节

### 4.1 LightGBM → C 转换原理

LightGBM 模型文件（`pm25_predictor_4features_fold.txt`）结构：
- 1000 棵树，每树 `num_leaves=31`（30个内部节点 + 31个叶子）
- 每节点：`split_feature`（0-3）、`threshold`、`left_child`、`right_child`
- 每叶子：`leaf_value`（预测值）

转换为 5 个 C 常量数组：
```
pm25_thresholds[1000][30]   — float, 每个分裂节点的阈值
pm25_features[1000][30]     — uint8_t, 每个节点使用哪个特征
pm25_left[1000][30]         — int8_t, 左子节点索引（<0=叶子）
pm25_right[1000][30]        — int8_t, 右子节点索引
pm25_leaves[1000][31]       — float, 叶子预测值
```

所有数组标注 `PROGMEM`，存入 Flash（ESP32 MMU 直接映射读取）。

### 4.2 关键发现：leaf_value 已含学习率

调试过程中发现：LightGBM 模型文件中 `leaf_value` **已经乘过了学习率（shrinkage）**，预测时直接累加即可。不能再次乘以 `shrinkage`，否则会双重缩放导致预测值严重偏差。

验证：4组测试数据的 LightGBM 库预测 vs 手动C遍历结果 **完全一致（diff < 0.000001）**。

### 4.3 子节点索引约定

```
child >= 0  → 内部节点，直接 0-based 索引到数组位置
child < 0   → 叶子节点，-1 → leaf[0], -2 → leaf[1], ...
```

### 4.4 模型参数

- 模型类型：LightGBM 梯度提升回归树
- 特征数量：4（temperature, co2, tvoc, humidity）
- 特征范围：
  - 温度：18.33 ~ 24.61 °C
  - CO2：424.95 ~ 908.56 ppm
  - TVOC：0 ~ 4568.4 ppb
  - 湿度：26.76 ~ 66.86 %
- 树数量：1000
- Flash 占用：~330 KB

### 4.5 性能

- ESP32-S3 @240MHz，1000棵树遍历 < 1ms
- 每 500ms 调用一次（随 `DataRead_ReadAll` 周期）
- 使用 `pgm_read_byte` / `pgm_read_float` 从 Flash 读取
- 无堆内存分配（纯栈变量）

## 五、数据流

```
AHT20(温湿度) + ENS160(CO2/TVOC)
        │ 每500ms
        ▼
   DataRead_ReadAll()
        │
        ▼
   pm25Predict(temp, eco2, tvoc, humi)  ← AI推理（1000棵树）
        │
        ▼
   sensorData.pm25
        │
        ├── MQTT 上报 → 服务器 (data_report JSON)
        └── LVGL UI  → envScreen "PM2.5: xx.x ug/m3"
```

## 六、如何使用 / 更新模型

如果朋友重新训练了模型：

```bash
# 1. 把新模型文件放到 model 目录
cp 新模型.txt SmartDesktopCube-IoT-model/pm25_predictor_4features_fold.txt

# 2. 运行转换脚本
cd SmartDesktopCube-IoT-model
python convert_model_to_c.py

# 3. 复制到项目
cp pm25_model_data.h ../SmartDesktopCube-IoT/Smart\ Desktop\ Cube\ IoT/src/

# 4. 重新编译固件（PlatformIO Upload）
```
