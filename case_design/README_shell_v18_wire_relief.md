# Smart Desktop Cube 外壳 v18：内部走线修正版

## 基础

v18 基于 v17，只修内部走线和前侧小镂空问题。

## 改动

- DC 电源模块和 ESP32-S3 卡槽的内侧导轨改为分段结构。
- DC 电源模块和 ESP32-S3 卡槽的内侧上方限位唇改为分段结构。
- 分段之间形成走线缺口，杜邦线可以从模块侧边/上方出来。
- 保留外侧导轨和前端限位，模块仍然能被固定。
- 正面靠滑块侧的小镂空位置增加上下两个小遮挡唇，尽量减少可见空洞。

## 未改变

- 主体外形尺寸保持约 117 x 138 x 118 mm。
- 整面前压框保持 v17。
- 右侧滑条保持 v17。
- 后盖保持 DC 圆孔、Type-C 矩形孔和通风口。
- 顶部透明窗片保持不变。

## 走线建议

- DC 电源模块的输出线从靠中间的分段缺口走出。
- ESP32-S3 的杜邦线从靠中间的分段缺口或右侧线槽走出。
- 屏幕线从右侧线槽进入 ESP32-S3 区域。
- 传感器线可以沿后开口整理，避免压在屏幕凹槽后方。
