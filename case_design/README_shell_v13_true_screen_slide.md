# Smart Desktop Cube 外壳 v13：真正侧插屏幕滑板版

## v13 修正目标

v13 针对 v12 的问题重做屏幕结构：

- 前面板改为平整面，只保留一个矩形屏幕窗口。
- 屏幕不再靠前壳/前压框固定。
- 新增完整的屏幕滑板件，不再用几个分散小支撑块代替。
- 主体内部增加连续上下导轨，滑板从右侧插入。
- 滑板自带右侧锁止盖和线束鼓包，插入后防止屏幕退出，并容纳杜邦线。

## 输出文件

- `smart_cube_shell_v13_body_true_screen_slide.stl`：主体，带平整前脸、矩形屏幕窗口、连续滑槽。
- `smart_cube_shell_v13_screen_slide_tray_with_wire_cover.stl`：屏幕滑板/滑块，带线束盖。
- `smart_cube_shell_v13_back_cover_rect_ports_vents.stl`：后盖，保留 DC/Type-C 大矩形口和百叶窗。

## 外形尺寸

- 主体：约 122 x 140 x 118 mm。
- 屏幕滑板：约 89 x 132 x 90 mm。
- 后盖：约 18 x 138 x 120 mm。
- 顶部透明窗片：约 48 x 36 x 1.8 mm。

坐标约定：X 为前后深度，Y 为左右宽度，Z 为高度。屏幕滑板沿 Y 方向从右侧插入。

## 前面板

前面板现在是平整结构：

- 不再有独立前壳。
- 不再有复杂前压框。
- 只保留一个矩形屏幕显示窗口。
- 显示屏的固定由侧插滑板和主体内部滑槽完成。

## 侧插滑槽

主体内部有连续导轨：

- 下导轨承托滑板下滑舌。
- 上导轨限制滑板上边。
- 后侧背轨限制滑板向内晃动。
- 左端止挡用于确定插入终点。
- 右侧通过滑板自带侧盖和螺丝孔锁止，防止滑板退出。

这不是几个分散支撑块，而是一套连续的侧插轨道。

## 屏幕滑板

屏幕滑板是独立打印件：

- 显示屏先固定在滑板上。
- 滑板带上下滑舌，用来插入主体滑槽。
- 滑板中间有显示窗口开口，不挡屏幕显示区域。
- 滑板背面中部开 SD 卡槽避让，不硬顶屏幕背面凸起。
- 滑板右侧带外露盖板和线束鼓包，杜邦线可以从这里向后走。

## 装配顺序

1. 将显示屏安装到屏幕滑板上。
2. 将显示屏杜邦线从滑板右侧线束鼓包区域引出。
3. 从主体右侧把整块屏幕滑板插入连续滑槽。
4. 推到左端止挡后，使用右侧锁止螺丝固定滑板。
5. 从后方安装 ESP32-S3、DC 电源模块和传感器。
6. 将屏幕杜邦线接到 ESP32-S3。
7. 装后盖并测试 DC/Type-C 插入稳定性。

## 保留结构

v13 保留了 v11/v12 中已经确认需要的结构：

- DC 和 ESP32-S3 后插式底部卡槽。
- DC 和 Type-C 后盖大矩形接口窗口。
- 后盖百叶窗和主体侧向通风孔。
- BH1750 顶部透明窗。
- 顶部三个独立传感器卡槽。

## 仍需实测

为了把 v13 进一步收紧到可打印终版，需要实测：

- 显示屏 PCB 长宽。
- 显示屏厚度。
- 背面 SD 卡槽位置和凸起高度。
- 排针位置、排针方向、杜邦线插上后的最大外扩。
- 屏幕可视区与 PCB 外形边缘的偏移。
