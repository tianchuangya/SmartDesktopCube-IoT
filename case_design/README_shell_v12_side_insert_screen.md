# Smart Desktop Cube 外壳 v12：侧插式屏幕与可拆线束盖版

## v12 修正目标

v12 主要修正 v11 的屏幕装配问题：

- 去掉独立前屏幕压框。
- 屏幕改为从右侧滑入主体。
- 右侧线束区域改为可拆卸盖板。
- 考虑屏幕背面 SD 卡槽凸起，不在屏幕后方中部硬顶。
- 通过边缘滑轨、左端止挡和右侧可拆盖固定屏幕，降低按压和摇晃时屏幕移动的风险。

## 输出文件

- `smart_cube_shell_v12_body_side_insert_screen.stl`：主体。
- `smart_cube_shell_v12_screen_side_lock_wire_cover.stl`：屏幕右侧可拆锁止盖/线束盖。
- `smart_cube_shell_v12_back_cover_rect_ports_vents.stl`：后盖，保留 DC/Type-C 大矩形接口和百叶窗。
- `smart_cube_shell_v12_top_clear_lens.stl`：顶部 BH1750 透明窗片占位件。
- `smart_cube_shell_v12_side_insert_screen_preview.blend`：Blender 预览文件。

## 外形尺寸

- 主体：约 118 x 138 x 118 mm。
- 屏幕侧盖：约 93 x 8 x 74 mm。
- 后盖：约 18 x 138 x 120 mm。
- 顶部透明窗片：约 48 x 36 x 1.8 mm。

坐标约定：X 为前后深度，Y 为左右宽度，Z 为高度。屏幕从 +Y 右侧滑入。

## 屏幕装配方式

屏幕不再从前方压入，而是侧插：

1. 拆下右侧屏幕线束盖。
2. 将屏幕从右侧开口滑入主体前部滑槽。
3. 屏幕 PCB 上下边由上下滑轨承托。
4. 屏幕左端顶到左侧止挡，完成左右定位。
5. 杜邦线从右侧大通道向后走线，连接到底部 ESP32-S3 区域。
6. 装回右侧可拆盖，侧盖压住屏幕右侧边缘，同时覆盖线束通道。

## 屏幕背面 SD 卡槽处理

屏幕背面中部可能有 SD 卡槽或其他凸起。v12 的屏幕背部不做整面压板，而是：

- 用上下后支撑轨承托屏幕边缘。
- 用四个角部支撑块防止屏幕被按进去。
- 中部留空，避免 SD 卡槽和焊点被硬顶。

这样处理后，按压屏幕时受力会传到边缘支撑和主体框架，而不是压到 SD 卡槽。

## 右侧可拆盖

右侧可拆盖有两个作用：

- 锁止屏幕，防止屏幕从右侧滑出。
- 保护和容纳屏幕杜邦线，避免线束裸露或被外壳边缘压住。

盖板带外鼓线束空间，不是实心挡板。实际装配时如果杜邦线较硬，可以继续把这部分加高或改成更大的半开放盖。

## 保留的 v11 结构

v12 保留以下结构：

- DC 和 ESP32-S3 后插式底部卡槽。
- DC 和 Type-C 后盖大矩形接口窗口。
- 后盖百叶窗和主体侧向通风孔。
- BH1750 顶部透明窗。
- 顶部三个独立传感器卡槽。

## 仍需实测

这一版是按可装配优先设计。要进一步保证屏幕完全适配，需要实测：

- 屏幕 PCB 实际长宽。
- 屏幕整体厚度。
- 背面 SD 卡槽凸起高度和位置。
- 排针焊在屏幕哪一侧，杜邦线插上后的最大外扩尺寸。
- 触摸屏/显示屏边框实际可压区域，避免压到显示有效区。
