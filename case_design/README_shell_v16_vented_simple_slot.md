# Smart Desktop Cube 外壳 v16：简单插槽通风增强版

## 基础

v16 基于 v15，只增强通风，不改变整体结构。

## 改动

- 右侧简单滑条增加 2 条横向通风口。
- 后盖上半部分增加 4 条横向通风口。
- 主体、前屏幕压框、后盖接口位置保持 v15 的简单方案。

## 透明窗片材料

顶部透明窗片建议使用：

- 首选：透明亚克力片，厚度 1.5 到 2.0 mm。
- 更耐冲击：透明 PC 片，厚度 1.5 到 2.0 mm。
- 临时演示：透明 PETG 打印件，但透光性不如亚克力和 PC。

不建议普通玻璃，容易碎，边缘处理也麻烦。
