# Smart Desktop Cube 外壳 v8：按公开模块尺寸放大兼容版

## 参考尺寸

- ESP32-S3-DevKitM-1：62.74 x 25.40 mm。
- 2.4 inch ILI9341 SPI TFT 模块：约 77.18 x 42.72 mm，可视区约 36.72 x 48.96 mm。
- HLK-LD2410B：约 7 x 35 mm。
- AHT21 常见小板：约 16 x 11 mm。
- ENS160+AHT21 常见组合板：约 24 x 20 x 3 mm。
- BH1750 GY-302 常见板：约 13.9 x 18.5 mm。

## v8 改动

- 主体外形放大到约 93.3 x 108.0 x 98.0 mm。
- ESP32 底部轨道按 68 x 32 mm 预留，覆盖 ESP32-S3-DevKitM-1 外形并留装配余量。
- 屏幕改为前装结构，入口按 86 x 64 mm 预留，避免从背面塞不进去。
- 前压框可视窗口放大到约 70 x 54 mm，负责屏幕正面压紧。
- 传感器插槽放大到约 32 x 25 mm，可容纳 ENS160+AHT21 组合板，并兼容较小的 AHT21/BH1750 小板。
- LD2410B 雷达仓加宽到 42 mm，给板宽、焊点和导线留空间。
- 后盖 Type-C 与 DC 5.5 x 2.1 mm 开孔为贯穿孔，接口附近保留薄壁避让，并增加外圈加强结构。

## 仍需实物确认

公开尺寸只能保证外形大致兼容，不能保证所有店铺版本完全一致。重点需要实测：

- 屏幕 PCB 实际外形、排针方向、触摸排线或排针高度。
- ESP32-S3 开发板 USB-C 座相对板边位置。
- DC 座螺母、焊脚和导线折弯空间。
- 传感器模块是否带直针、弯针或杜邦线插头。

建议打印前先用低填充小样或纸板/亚克力激光样检查卡槽，确认后再完整打印。
