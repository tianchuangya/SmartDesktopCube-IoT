# Smart Desktop Cube 外壳 v5：完整前壳版本

v5 修正点：
- v3/v4 前面更像框架，没有完整前壳面板。
- v5 重新生成了真实前壳：前面板为实体，只保留屏幕开窗和 LD2410B 雷达开窗。
- 侧壁、顶壁、底壁完整；后部开放，配合 `smart_cube_shell_v4_back_cover_open_ports.stl` 使用。
- 后侧保留 Type-C 和 DC 5.5x2.1 接口区域，接口区域局部薄壁。

推荐组合：
- 主体：`smart_cube_shell_v5_real_front_body.stl`
- 后盖：`smart_cube_shell_v4_back_cover_open_ports.stl`

注意：
- 这仍是可调式装配壳，不是精确卡死版。
- Type-C 口和 DC 口位置是假设接口从后侧伸出；如果你实物 USB-C 方向不是后侧，需要改口位置。
- 顶部通风目前做成外部提示筋，不是真正贯穿槽；如果确认传感器位置后，可以再做实际通风开孔版。
