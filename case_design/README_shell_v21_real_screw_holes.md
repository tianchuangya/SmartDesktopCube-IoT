# Smart Desktop Cube 外壳 v21：真实螺丝孔版

## 基础

v21 基于 v20，只修前壳、后壳和主体对应螺丝孔。

## 修正

- 前压框四角螺丝孔改为真实通孔。
- 后盖四角螺丝孔改为真实通孔。
- 主体前侧四个螺丝座增加真实导孔。
- 主体后侧四个螺丝座增加真实导孔。
- 螺丝孔在外壳生成阶段切出，避免后期布尔切割破坏主体外形。

## 孔径

- 前压框/后盖通孔半径约 2.4 mm。
- 主体导孔半径约 1.8-1.9 mm。

实际打印后可根据螺丝型号微扩孔。建议先试 M2 或 M2.5 自攻螺丝。

## 保持不变

- 主体外形保持约 117 x 138 x 118 mm。
- 透明窗两侧真实通风孔保持 v20。
- 整面前压框、右侧滑条、后盖接口、顶部透明窗片均保持当前结构。
