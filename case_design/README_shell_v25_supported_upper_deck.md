# Smart Desktop Cube 外壳 v25：上层模块平台边缘支撑版

## 修正目标

v25 修复主体内部上层模块插槽平台局部悬空的问题。

## 修正方式

- 保留中间走线窗口。
- 在上层模块平台左右两侧增加边缘支撑梁。
- 在平台前后位置增加短连接筋。
- 让上层模块平台连接到外框，不再是中间悬空平台。

## 保持不变

- 主体外形保持约 117 x 138 x 118 mm。
- 前压框、右侧滑条、后盖、顶部透明窗片保持 v24。
- 后盖对应主体螺丝孔保持贯穿。
- 透明窗侧边通风孔保持贯穿。
