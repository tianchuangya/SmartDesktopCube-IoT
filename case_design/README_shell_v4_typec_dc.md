# Smart Desktop Cube 外壳 v4：Type-C 与 DC 口版本

新增内容：
- 后侧 Type-C 口，按 `约 13 x 8 mm` 开口预留。
- 后侧 DC 圆口，按 DC 5.5 x 2.1 插座预留，打印孔内径约 `8.4 mm`，外侧有加强环。
- 接口区域局部墙厚按约 `1.2 mm` 做薄，避免 Type-C 和 DC 插头插入时被厚墙挡住。

注意：
- DC 5.5 x 2.1 指的是插头/插座电气规格，不等于面板安装孔一定是 5.5 mm。常见面板孔通常需要 8 mm 左右，具体要看你买的 DC 母座外壳尺寸。
- Type-C 口位置按 ESP32-S3 开发板后侧出线假设设计。如果你的 ESP32 USB 口朝侧面或朝下，需要改口位置。
- 这版仍是可调式结构，不承诺精确孔位完美适配。
