# Smart Desktop Cube 外壳 v23：后侧主体空心螺丝座版

## 修正目标

v23 专门修复后盖对应主体的四个螺丝座仍然像实心的问题。

## 修正方式

- 不再用圆柱实体再布尔挖孔的方式做后侧主体螺丝座。
- 后侧主体螺丝座改为四块实体围成的环形座。
- 中间天然留空，螺丝可以直接进入。
- 避免后期布尔切割破坏主体外形。

## 保持不变

- 主体外形保持约 117 x 138 x 118 mm。
- 前压框四角通孔保持不变。
- 后盖四角通孔保持不变。
- 顶部透明窗两侧真实通风孔保持不变。
- 右侧滑条和后盖接口保持不变。
