# Smart Desktop Cube 外壳 v17：整面前压框与屏幕侧向入口版

## 基础

v17 基于 v16，只修屏幕装配和局部通风，不改变内部模块布局、后盖接口逻辑和整体尺寸。

## 改动

- 前屏幕压框外形放大到接近整个正面，尺寸约 5 x 138 x 118 mm。
- 前压框内部显示窗口保持原来级别，约 84 x 62 mm。
- 主体前方屏幕凹槽加深，给显示屏留出更明确的放置空间。
- 主体右侧新增屏幕侧向插入口，让右侧线槽与前方屏幕凹槽连通。
- 右侧靠近顶部透明窗位置新增 2 条通风口。
- 保留右侧滑条原来的 2 条通风口。
- 后盖保持 v16：DC 圆孔、Type-C 矩形孔、上部通风口。

## 装配思路

1. 显示屏从正面放入更深的矩形凹槽。
2. 如果屏幕侧边排针或杜邦线需要空间，可从右侧插入口进入/理线。
3. 前压框覆盖整个正面，并用四角螺丝压住屏幕边缘。
4. 右侧滑条插入侧边滑槽，遮挡和保护杜邦线侧槽。

## 仍需实测

- 显示屏 PCB 长宽和背面 SD 卡槽高度。
- 前压框四角螺丝是否避开屏幕 PCB 和排针。
- 右侧插入口是否足够容纳杜邦线插头。
