# Smart Desktop Cube Case v20

This package contains the current 3D model files for the Smart Desktop Cube enclosure.

## How to Preview

Open one of these files:

- `preview/SmartDesktopCube_case_v20_preview.blend`
  - Best if you use Blender.
- `preview/SmartDesktopCube_case_v20_all_parts_preview.glb`
  - Good for quick viewing in Windows 3D Viewer or other GLB viewers.
- `preview/SmartDesktopCube_case_v20_all_parts_preview.stl`
  - Good for slicers, but it is mainly for preview.

## How to Print

Use the individual STL files in `print_parts_stl/`:

- `01_body.stl`
- `02_front_bezel.stl`
- `03_side_slider.stl`
- `04_back_cover.stl`
- `05_top_clear_lens_placeholder.stl`

The clear lens STL is only a size placeholder. For the real top light window, use a 1.5-2.0 mm transparent acrylic sheet or transparent PC sheet.

## Notes

- The files are intentionally small because the model uses simple geometry.
- Do not judge whether the package is valid by ZIP size.
- If a file cannot open, try Blender 5.x, PrusaSlicer, Cura, Bambu Studio, Windows 3D Viewer, or MeshLab.
- For 3D printing, import the separate STL files, not only the preview file.
