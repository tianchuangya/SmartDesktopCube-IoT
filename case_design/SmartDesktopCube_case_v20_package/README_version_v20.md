# Smart Desktop Cube 外壳 v20：透明窗侧边真通风孔版

## 基础

v20 基于 v19，只修顶部透明窗附近左右侧通风孔。

## 修正

- 顶部透明窗附近左右两侧的通风口重新建模为真实贯穿孔。
- 不再使用合并后大范围切孔，避免布尔切割破坏主体外形。
- 主体外形保持约 117 x 138 x 118 mm。

## 保持不变

- 中心走线窗口保持 v19。
- 整面前压框保持不变。
- 右侧滑条保持不变。
- 后盖 DC 圆孔、Type-C 孔和通风孔保持不变。
- 顶部透明窗片保持不变。
