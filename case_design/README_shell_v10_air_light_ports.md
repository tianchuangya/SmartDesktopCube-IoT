# Smart Desktop Cube 外壳 v10：通风、透光、接口固定版

## v10 解决的问题

v10 在 v9 基础上重点修正四类问题：

- 顶部传感器卡槽互相挤压的问题。
- 后盖没有真实 Type-C 和 DC 外部插入口的问题。
- 空气质量传感器被密闭外壳包住的问题。
- BH1750 光照传感器被不透明外壳遮挡的问题。
- 屏幕一侧排针接上杜邦线后，线束必须连续走到 ESP32-S3，不能被内部结构截断。

## 外形尺寸

- 主体：约 113 x 132 x 116 mm。
- 前屏幕压框：约 12 x 126 x 98 mm。
- 后盖：约 17 x 134 x 118 mm。
- 顶部透明窗片占位件：约 46 x 34 x 1.8 mm。

坐标约定：X 为前后深度，Y 为左右宽度，Z 为高度。

## 顶部传感器区

顶部传感器区改为三个独立卡槽：

- LD2410C 卡槽：按约 42 x 34 x 20 mm 包络预留。
- ENS160 + AHT21 卡槽：按约 46 x 38 x 20 mm 包络预留。
- BH1750 卡槽：按约 50 x 28 x 20 mm 包络预留。

三个卡槽之间有独立隔墙和间距，不再把两个模块挤在同一条连续窄槽里。

## 通风设计

- 后盖上半部分增加横向百叶窗通风孔，位置对准空气质量传感器区域。
- 主体左右侧壁上半部分增加侧向通风孔，减少单面进风导致的读数滞后。
- ENS160 + AHT21 不建议完全贴死在壳体内壁，应让传感器裸露面朝向通风区。

## 光照设计

- BH1750 上方开了顶部透光窗口。
- 同时生成了 `smart_cube_shell_v10_top_clear_lens.stl` 作为透明窗片尺寸占位。
- 实物建议使用 1.5 到 2.0 mm 透明亚克力片或 PC 片，不建议用普通玻璃，玻璃脆且边缘处理麻烦。
- 如果只能 3D 打印，透明 PETG 可以作为演示用，但透光均匀性和透明度不如亚克力/PC。

## 后部接口设计

后盖已开真实贯穿孔：

- DC 5.5 x 2.1 接口孔：位于左下模块区，采用圆孔 + 方形避让组合。
- ESP32-S3 Type-C 接口孔：位于右下模块区，采用加大的矩形避让孔。

两个接口孔周围有加强框。防后退压块改为压模块两侧边缘，不压接口中心线，避免挡住插头。

## 模块固定方式

- DC 电源管理模块使用底部滑入式 U 型卡槽，按约 84 x 52 x 28 mm 包络预留。
- ESP32-S3 使用底部滑入式 U 型卡槽，按约 82 x 52 x 28 mm 包络预留。
- 两个底部模块都由卡槽限制左右和上下晃动，后盖压块限制向后退。
- 从外部插入 DC 或 Type-C 线时，受力路径为：插头 -> 模块接口 -> 模块 PCB -> 卡槽/后盖压块，而不是直接拉扯线材。

## 屏幕线束通道

屏幕仍采用前装方式。前压框和主体右侧预留连续线束通道：

- 屏幕一侧排针接上杜邦线后，可以从屏幕侧边直接向后走线。
- 线束通道延伸到底部 ESP32-S3 区域，不需要中途断开杜邦线。
- 这部分按“射线式线束”处理，而不是只按 L 形硬件外形处理。

## 打印建议

第一版建议使用 PETG：

- PLA 更容易打印，但接口反复插拔、夏天高温或长时间运行时更容易变形或脆裂。
- PETG 韧性和耐热更适合演示用外壳。
- ABS/ASA 更强，但翘边和气味问题更明显，学校环境不一定方便。

建议参数：

- 层高：0.20 mm。
- 喷嘴：0.4 mm。
- 壁厚：至少 3 道墙，接口和螺丝区域建议 4 道墙。
- 填充：20% 到 30%，Gyroid 或 Grid。
- 后盖平放打印。
- 前压框平放打印。
- 主体建议以后开口朝上或侧放方式测试切片，优先减少前面板和顶部窗口支撑。

## 仍需实测后才能做精准版

v10 是“可装入优先”的结构版，还不是最终精准量产版。要把接口完全对齐，需要继续测量：

- ESP32-S3 PCB 长宽高。
- ESP32-S3 Type-C 口中心到 PCB 左右边、上下边的距离。
- DC 电源模块 DC 座中心到 PCB 左右边、上下边的距离。
- 屏幕 PCB 长宽、厚度、排针方向、杜邦线插上后的最大厚度。
- 杜邦线从屏幕到 ESP32-S3 的自然弯折半径。
