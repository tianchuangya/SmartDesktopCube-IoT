# Smart Desktop Cube 外壳 v14：v12 修正版

## v14 修正内容

v14 基于 v12 回退基线修改，不采用 v13 的大滑板方案。

主要修正：

- 屏幕侧盖改为完整一体盖板，不再像几个分散方块。
- 正面屏幕区域改为更深的矩形嵌入槽，表面保持平整，不做额外装饰图形。
- 屏幕边缘由更深的前部凹槽和内部连续导轨共同限制，降低按压屏幕时向内移动的风险。
- DC 电源模块和 ESP32-S3 卡槽上方的限位唇加宽，并改成连续压板结构。
- 后盖 DC 口由超大矩形窗口改为小圆孔，并保留小型下方避让。
- Type-C 口仍保留矩形孔，但比早期大窗口更收敛。

## 外形尺寸

- 主体：约 118 x 138 x 118 mm。
- 屏幕侧盖：约 94 x 12 x 92 mm。
- 后盖：约 18 x 138 x 120 mm。
- 顶部透明窗片：约 48 x 36 x 1.8 mm。

## 正面屏幕区

正面只保留平整矩形结构：

- 外层是更深的矩形嵌入槽。
- 内部是矩形显示窗口。
- 没有额外图形或复杂前壳。
- 屏幕比 v12 更向内嵌，减少屏幕凸出和晃动。

## 屏幕侧盖

侧盖改为完整一体式：

- 整体是连续盖板。
- 线束鼓包与盖板连成一体。
- 内侧保留线束避让空间。
- 通过螺丝孔锁到主体右侧。

## 后盖接口

- DC 口改为约 12 mm 直径圆形孔，并带一个小的下方避让。
- Type-C 口为收窄后的矩形孔。
- DC 和 Type-C 周围都保留加强结构。

注意：DC 口如果最终模块的 DC 座中心偏移较大，仍需要根据实物再微调孔位。

## 卡槽固定

DC 电源管理模块和 ESP32-S3 仍从后方插入：

- 底部有承托板。
- 两侧有导轨。
- 上方有限位唇。
- v14 将上方限位唇加宽为连续压板，约束能力比 v12 更强。

## 当前建议

v14 比 v12 更适合作为当前模型继续检查。v13 不建议继续使用。
