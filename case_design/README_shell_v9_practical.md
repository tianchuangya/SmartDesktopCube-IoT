# Smart Desktop Cube 外壳 v9：可装配优先实用版

## 设计目标

v9 不再沿用 v8 的偏紧结构，目标改为先保证硬件能实际放入、接口能对齐、模块能固定、插拔线材时不会把模块顶松。

## 来自 `关于硬件.docx` 的尺寸

- LD2410C：16 x 22 mm。
- 多路 DC 电源模块：PCB 59.5 x 26.5 mm，DC 接口 5.5 x 2.1 mm。
- ENS160 + AHT21：19.6 x 24.3 mm，手工测量。
- BH1750：32.6 x 15.1 mm。
- TFT ILI9341：文档中记录了接线引脚，但未给出外形尺寸。
- ESP32-S3：文档中未给出外形尺寸，v9 按常见 ESP32-S3 开发板外形并额外加入排针和杜邦线余量处理。

## 外形尺寸

- 主体：108 x 126 x 112 mm。
- 前屏幕压框：8 x 120 x 92 mm。
- 后盖：12 x 126 x 112 mm。

坐标约定：X 为前后深度，Y 为左右宽度，Z 为高度。

## 关键结构

- 前面板采用大开口前装结构，屏幕和一侧排针/杜邦线可以从前方放入。
- 屏幕右侧预留线槽，用来容纳一侧排针形成的 L 形突出和杜邦线折弯。
- ESP32-S3 和 DC 电源模块采用底部滑入式 U 型卡槽，不再使用悬空压梁。
- ESP32-S3 卡槽按 78 x 46 x 24 mm 包络预留，包含 PCB、排针、杜邦线插头高度余量。
- DC 电源模块卡槽按 80 x 52 x 24 mm 包络预留，覆盖 59.5 x 26.5 mm PCB，并给 DC 座、焊点、导线留空间。
- 后盖内侧增加 ESP32 和 DC 模块的防后退压块，插 Type-C 或 DC 线时，模块尾端会被后盖顶住，降低松动风险。
- 后盖 Type-C 与 DC 孔采用偏大的贯穿开孔，因为不同模块接口位置会有偏差。
- 后盖螺丝孔改为连接到盖板的实心垫块和加强肋，不再是悬空空心圆柱。
- 主体后侧螺丝座也增加侧向/上下加强肋，避免打印时形成孤立悬空结构。

## 打印建议

推荐先用 PETG 打印。理由是 PETG 比 PLA 更耐热、更抗冲击，接口反复插拔时不容易脆裂；比 ABS 更容易打印，翘边风险较低。

建议参数：

- 材质：PETG。
- 层高：0.20 mm。
- 喷嘴：0.4 mm。
- 壁厚：至少 3 道墙，约 1.2 mm。
- 顶/底层：5 层以上。
- 填充：20% 到 30%，Gyroid 或 Grid。
- 接口、螺丝柱、卡槽区域建议局部提高填充或增加墙数。
- 主体建议后开口朝上或侧放打印，减少前面板大开口周围支撑。
- 后盖平放打印。
- 前压框平放打印。

## 仍需实物确认

v9 已经按“能放入”放大，但不能保证接口绝对完美对齐，因为以下数据目前没有实测：

- ESP32-S3 开发板实际长宽、Type-C 口到 PCB 边缘的偏移。
- DC 电源模块 DC 座中心到 PCB 边缘的偏移。
- TFT ILI9341 模块 PCB 外形、排针在长边还是短边、排针焊接方向、杜邦线插头高度。
- 杜邦线实际折弯半径。

建议下一步用游标卡尺补量这些接口偏移，再做 v10 精准定位版。
