# Smart Desktop Cube 外壳 v24：后壁贯穿螺丝孔版

## 修正

v24 修复 v23 的问题：后侧主体螺丝座虽然中间为空，但主体后壁没有打穿，导致从后盖方向看仍像实心。

## 处理方式

- 在主体后壁四个后盖螺丝孔位置先切贯穿孔。
- 再保留后侧环形螺丝座。
- 后盖通孔保持不变。
- 主体外形复核为 117 x 138 x 118 mm。

## 孔位检查

已对四个后侧螺丝孔附近做 STL 几何检查，孔位处存在圆孔内壁三角面，不再是实心。
