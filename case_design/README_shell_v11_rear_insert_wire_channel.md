# Smart Desktop Cube 外壳 v11：后插模块槽与大线束通道版

## v11 修正点

v11 针对 v10 继续修正以下问题：

- DC 和 Type-C 接口统一改为大矩形外部插入口。
- DC 电源管理模块和 ESP32-S3 的卡槽后方取消挡板，模块可以从后盖方向直接滑入。
- 屏幕右侧线束通道放大，并做成可见的侧向通道，避免杜邦线被内部结构截断。
- 继续保留后盖百叶窗、侧向通风孔和顶部 BH1750 透光窗。

## 外形尺寸

- 主体：约 117 x 136 x 118 mm。
- 前屏幕压框：约 12 x 130 x 102 mm。
- 后盖：约 18 x 138 x 120 mm。
- 顶部透明窗片占位件：约 48 x 36 x 1.8 mm。

坐标约定：X 为前后深度，Y 为左右宽度，Z 为高度。

## 后插式模块槽

底部两个主模块槽改为后插式：

- 打开后盖。
- 从后方把 DC 电源管理模块沿左侧 U 型槽推入。
- 从后方把 ESP32-S3 沿右侧 U 型槽推入。
- 卡槽前端保留限位，防止模块继续向前顶到屏幕区域。
- 卡槽后方不再有挡板，不会阻碍模块放入。
- 装上后盖后，后盖两侧边缘压块限制模块向后退出。

注意：后盖压块只压模块边缘，不压 DC/Type-C 插头中心线。

## 后盖接口

后盖有两个统一的大矩形插入口：

- 左下：DC 电源管理模块接口窗口。
- 右下：ESP32-S3 Type-C 接口窗口。

这里没有再强行做 DC 圆孔。原因是目前缺少 DC 座中心相对 PCB 边缘的精确偏移。先用矩形大窗口保证能插、能演示、能容错；后续实测后可以改为更贴合的圆角孔或圆孔加矩形避让。

## 屏幕线束通道

屏幕右侧不再按一个小 L 形空间处理，而是按连续线束处理：

- 前屏幕压框右侧开大侧出口。
- 主体右侧从屏幕边缘到后部服务口开了明显的大线束通道。
- 屏幕排针接上杜邦线后，线束可以从屏幕右侧直接向后走，再转到底部 ESP32-S3 区域。
- 线束不需要中途断开，也不会被前框或内部隔板截断。

## 通风与透光

- 后盖上半部分保留百叶窗，服务 ENS160/AHT21 空气质量与温湿度读数。
- 主体两侧保留侧向通风孔，避免只靠后盖单侧进风。
- BH1750 上方保留顶部透明窗结构。
- 透明窗建议使用 1.5 到 2.0 mm 透明亚克力或 PC 片。

## 装配顺序建议

1. 先把屏幕从前方放入前框区域。
2. 把屏幕杜邦线从右侧大通道向后理出。
3. 从后方滑入 DC 电源管理模块。
4. 从后方滑入 ESP32-S3，并把屏幕线束接到 ESP32-S3。
5. 放入顶部三个传感器模块。
6. 整理线束，确认不压住百叶窗和光照窗口。
7. 装上后盖，确认后盖压块压住模块边缘。
8. 从外部测试插入 DC 和 Type-C 线，检查模块是否后退或晃动。

## 仍需实测优化

v11 仍是可装配优先版。下一版要进一步变小、变准，需要补量：

- DC 座中心到 DC 电源模块 PCB 边缘的距离。
- ESP32-S3 Type-C 口中心到 ESP32-S3 PCB 边缘的距离。
- 屏幕 PCB 的真实外形、排针位置、插上杜邦线后的最大厚度。
- 杜邦线自然弯折半径。
