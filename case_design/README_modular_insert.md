# Smart Desktop Cube 可插拔硬件内胆 v1

文件：
- `smart_cube_modular_insert_v1.stl`：可直接切片打印的第一版内胆。
- `smart_cube_modular_insert_v1.scad`：尺寸参数说明和后续可编辑参考。

设计目标：
- 不直接改 607MB 的 `mzh51.stl` 外壳，先做可插入式内部骨架。
- 解决主控固定、屏幕固定、传感器朝向、LD2410B 雷达开窗、线材走线和后续拆换问题。

坐标和尺寸：
- 原模型包围盒约 `70.4 x 87.5 x 86.7 mm`，疑似按米导出但实际是毫米级外形。
- 内胆按 `X=深度、Y=宽度、Z=高度` 建模。
- 主体底板约 `64 x 80 mm`，两侧滑轨给外壳留约 2-3 mm 间隙。

模块布局：
- ESP32-S3 DevKitM-1：底板中央，四个 M2 预留柱，也可扎带固定。
- 2.4 寸 ILI9341 触控屏：前面板四角固定耳 + 上下托边。
- AHT21 / ENS160 / BH1750：顶部后侧三个小板插槽，靠近通风区，远离主控发热源。
- LD2410B：前上方独立雷达仓，避免被屏幕线材挡住。
- 电源/接口：后右侧小平台，旁边有扎带柱。
- 走线：中间开放线槽 + 三个扎带桥，左右侧预留出线口。

打印建议：
- 材料：PLA/PETG 均可，PETG 更耐热。
- 层高：0.2 mm。
- 壁厚：至少 3 道墙。
- 填充：15%-25%。
- 先用 20%-30% 缩短高度的局部试打确认 ESP32 和屏幕孔位，再完整打印。

需要你实测后反馈的关键尺寸：
1. ESP32-S3 开发板真实长宽和孔距。
2. ILI9341 屏幕 PCB 长宽、屏幕可视区、孔距。
3. 原外壳内部净空，尤其前面板到后盖的深度。
4. 你希望从后盖插入，还是从底部插入。


## v2 compact 更新

`smart_cube_modular_insert_v2_compact.stl` 是推荐优先试打版本。它把 v1 的外包围从约 `74 x 87 x 90 mm` 收缩到约 `63.6 x 81.2 x 78.4 mm`，更适合塞进原 `mzh51.stl` 的 70 x 87 x 87 mm 外形中。

优先打印 v2，不建议直接打印 v1。v1 保留作结构参考。
