# Smart Desktop Cube 外壳 v15：简单插槽版

## 设计方向

v15 回到简单可靠的结构，不继续堆复杂外壳：

- 保留内部 DC、ESP32-S3、传感器模块布局。
- 前面只做平整矩形屏幕嵌入槽。
- 屏幕从前方放入凹槽。
- 外面用一个简单前压框压住屏幕，四角预留螺丝孔。
- 右侧只做一条简单滑条，用来遮住/保护杜邦线侧槽。
- 后盖只开两个接口孔：DC 圆孔和 Type-C 矩形孔。

## 输出文件

- `smart_cube_shell_v15_body_simple_slot.stl`：主体。
- `smart_cube_shell_v15_front_bezel_4screw.stl`：前屏幕压框，四角螺丝孔。
- `smart_cube_shell_v15_side_simple_slider.stl`：右侧简单滑条。
- `smart_cube_shell_v15_back_cover_two_ports.stl`：后盖，两个接口孔。

## 外形尺寸

- 主体：约 117 x 138 x 118 mm。
- 前屏幕压框：约 5 x 116 x 90 mm。
- 右侧滑条：约 94 x 10 x 66 mm。
- 后盖：约 8 x 138 x 120 mm。
- 顶部透明窗片：约 48 x 36 x 1.8 mm。

## 前面屏幕结构

- 主体前面是平整面。
- 屏幕位置是一个更深的矩形凹槽。
- 前压框只负责压住屏幕边缘。
- 前压框四角有螺丝孔，可以后续手工扩孔或攻丝。
- 没有复杂图形、没有额外前侧大壳。

## 侧边滑块结构

侧边滑块回到最初 v1 那种简单长轨思路：

- 主体右侧有两条直线凹槽。
- 滑条上有上下两个长舌。
- 滑条沿侧边直线滑入。
- 作用只是遮住线束侧槽和保护杜邦线，不参与复杂承力。

## 后盖

后盖只保留简单接口：

- DC：圆孔。
- Type-C：矩形孔。

没有大面积复杂接口框。后续如果实物接口偏移，需要按实测移动孔位。

## 当前建议

v15 比 v14 更接近“简单可打印第一版”。后续应优先检查：

- 屏幕能否放入前方凹槽。
- 前压框四角螺丝位置是否避开屏幕 PCB。
- 右侧杜邦线是否能从线槽走出。
- DC 圆孔和 Type-C 孔是否与实物接口对齐。
