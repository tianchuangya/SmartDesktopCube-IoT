# Smart Desktop Cube 外壳 v3：可调式硬件装配方案

这版不是“完美卡槽”，而是可调式装配外壳。原因很直接：没有每块实物模块的精确长宽、孔距、排线方向和焊针高度，不能设计死卡槽并承诺完美适配。

## 推荐文件

- `smart_cube_shell_v3_body_adjustable.stl`：完整外壳主体，后盖开放。
- `smart_cube_shell_v3_back_cover.stl`：后盖。
- `smart_cube_fit_gauge_v3.stl`：小尺寸试装片，建议先打印它验证模块宽度/扎带固定方式。

## 外壳尺寸

- 主体外包围约：`78 x 96 x 92 mm`，单位 mm。
- 原 `mzh51.stl` 外包围约：`70.4 x 87.5 x 86.7 mm`。新壳比原壳更大，因为原壳没有给屏幕板、线材、ESP32 插针和传感器插槽留足空间。

## 模块布局

- 前面：2.4 寸 ILI9341 显示屏窗口 + 后侧托边。屏幕板用压片/泡棉/螺丝孔位固定，不做死卡槽。
- 前上：LD2410B 雷达窗口和内侧托架，避免塑料和线材挡住雷达方向。
- 底部：ESP32-S3 开发板滑轨 + 扎带桥。适配孔距不确定时更稳。
- 顶部后侧：AHT21 / ENS160 / BH1750 小模块插槽，靠近通风孔，远离主控发热区域。
- 中间：开放走线槽和扎带桥。
- 后盖：4 个 M2/M2.3 自攻螺丝柱位，后侧有出线空间。

## 打印建议

1. 先打印 `smart_cube_fit_gauge_v3.stl`，验证 ESP32 和屏幕 PCB 能否放进轨道。
2. 再低质量打印主体：0.2mm 层高、15%-20% 填充、PLA/PETG 均可。
3. 屏幕和 ESP32 先用 M2 螺丝、泡棉胶或扎带固定，不要一开始就追求完全卡死。
4. 如果要改成精确卡槽，需要你量：
   - ESP32-S3 板长宽、孔距、USB 口方向、排针高度。
   - ILI9341 屏幕 PCB 长宽、屏幕可视区尺寸、孔距、排线/触控板位置。
   - AHT21、ENS160、BH1750、LD2410B 每块板长宽和排针方向。
   - 电源模块尺寸和线径。

## 当前设计结论

这版可以作为答辩/样机装配的结构起点，但不能叫“完美适配”。合理说法是：采用可调式模块仓、扎带桥、滑轨和走线槽，降低不同模块尺寸误差对装配的影响。
