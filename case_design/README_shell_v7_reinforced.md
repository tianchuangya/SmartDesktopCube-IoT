# Smart Desktop Cube 外壳 v7：屏幕固定与背部接口加强版

v7 解决两个明确问题：
1. v6 前压框不一定能可靠固定屏幕。
2. 背部 Type-C / DC 开孔周围存在悬空和薄弱风险。

## 屏幕固定方案
- 屏幕从前面放入主体大开口。
- 主体内侧有后退限位台阶，防止屏幕继续往里掉。
- 四角有螺丝柱/压片位。
- 独立前压框 `smart_cube_shell_v7_front_screen_clamp_bezel.stl` 负责压住屏幕边缘。
- 前压框内侧有接触唇边，减少晃动。

## 背部接口加强
- Type-C 矩形通孔周围增加上下框和支撑筋。
- DC 5.5x2.1 圆口使用 8.6mm 左右通孔，并加厚圆环。
- DC 圆孔左右和下方增加加强肋，减少悬空边。

## 推荐打印组合
- 主体：`smart_cube_shell_v7_body_front_clamp_reinforced_ports.stl`
- 前压框：`smart_cube_shell_v7_front_screen_clamp_bezel.stl`
- 后盖：`smart_cube_shell_v7_back_cover_reinforced_open_ports.stl`

## 仍需确认
没有实测屏幕 PCB 和孔距前，仍不能承诺完美适配。v7 是可调装配方案，目标是能装、能固定、能走线，而不是死卡槽。
